Engineering Gotchas & Tribal Knowledge

Critical edge cases discovered through testing and production use that incoming developers must know.

⚠️ LSP UTF-8 Byte Framing

In LSP HTTP framing, Content-Length represents the byte count in UTF-8, not the character count. Documents with non-ASCII content (such as Thai characters, mathematical symbols, or emojis) will corrupt the stream if string.length is used instead of Buffer.byteLength() or Rust's as_bytes().len().

🔤 Typst Font Discovery

Typst does not automatically scan %LOCALAPPDATA%/typst/fonts. It only scans system fonts (C:\Windows\Fonts) and explicitly supplied paths. The backend auto-provisions fonts to %APPDATA%/com.kong.typst-editor/fonts/ and injects both --font-path and TYPST_FONT_PATHS across LSP, preview, and CLI compile.

📁 Windows Path Normalization

Tinymist produces URIs like file:///d:/try/typst/paper.typ, while Windows uses D:\Try\Typst\paper.typ. Always use normalizePath() (converting all slashes to \ and lowercase) before performing equality checks, otherwise jump-to-source will fail to identify the active editor file.

🖱️ Double-Click Protocol for Sync

Tinymist's preview client sends a jump event on every single click. To prevent typing, text selection, or casual cursor movements from constantly throwing the user across the document, the app gates bidirectional jumps behind a 400ms double-click threshold on both sides.

📦 Package Deprecation Auto-Patching

Certain popular community packages (like scienceicons:0.1.0) contain inline raw blocks without whitespace (e.g. ```<svg). In Typst 0.12+, this produces deprecation warnings. The Rust backend automatically checks and patches cached packages on startup, and editor formatting cleans them dynamically.

🛡️ Filesystem Root Guarding

Never allow raw path concatenation in Tauri commands. All CRUD operations run through resolve_inside(&root, &target) in Rust, strictly blocking path traversal attempts (such as ../../secret.txt) and rejecting paths outside the workspace folder.

Developer Quick Start & Commands

Commands to verify, run, test, and package the codebase from scratch.

1. Run in Development Mode

Spawns Vite frontend dev server and runs Tauri backend with hot reload:

npm run tauri dev

2. Run Test Suites

Run both frontend unit regression tests and Rust backend test suite:

# Run TypeScript unit tests (37 tests across 9 files) npm run test # Run Rust unit tests (19 tests) cargo test --manifest-path src-tauri/Cargo.toml

3. Build Production Installer

Produces optimized NSIS Windows standalone installer and portable binary in src-tauri/target/release/bundle/nsis/:

npm run tauri build

4. Clean Target Artifacts

If target disk size grows during development, use the automated cleanup utility:

powershell -ExecutionPolicy Bypass -File tools/clean-target.ps1
